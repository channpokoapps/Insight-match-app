# Meta（Instagram）連携の設定とアプリ審査

**このアプリ最大の関門。** ビジネス認証とアプリ審査の待ち時間が合計 2〜6 週間かかるため、
他の作業と並行して**最優先で着手する**（`OI-01`）。

コード側（Edge Function `meta-oauth` / `sync-worker`）は実装・デプロイ済み。
このドキュメントの作業がすべて終わると、アプリの「SNS 連携」ボタンが実際に動く。

---

## 0. 全体の流れ

| 段階 | 内容 | 待ち時間 |
| --- | --- | --- |
| A | Meta ビジネスポートフォリオ作成 + **ビジネス認証** | 数日〜2週間 |
| B | 開発者登録・アプリ作成・設定 | 即日 |
| C | **開発モード**でテストユーザーの実データ検証 | 即日〜 |
| D | 審査用の動画・説明を用意して**アプリ審査**申請 | 2〜4週間 |
| E | 承認後「ライブモード」へ切替 → 一般公開 | 即日 |

C まで進めば（審査を待たずに）自分のテストアカウントで
連携〜インサイト取得の動作確認ができる。

## 1. 事前に必要なもの

- [ ] 実名の Facebook 個人アカウント（本人確認できるもの）
- [ ] **Instagram ビジネス／クリエイターアカウント**（テスト用。個人アカウントは
      Instagram アプリ → 設定 → アカウントの種類とツール → 切り替え、で変更できる）
- [ ] そのInstagram と連携した **Facebook ページ**（無料。ビジネスポートフォリオから作成）
- [ ] 公開済みのプライバシーポリシー URL（[legal.md](legal.md) / `OI-03`。審査必須）

## 2. ビジネス認証（段階 A）

1. https://business.facebook.com → ビジネスポートフォリオを作成
2. 設定 → **ビジネス認証（Business Verification）** → 事業情報・書類を提出
   （個人事業主は開業届の控えなど）
3. 承認メールを待つ（この間に段階 B・C を進める）

## 3. 開発者登録とアプリ作成（段階 B）

1. https://developers.facebook.com → 「スタート」から開発者登録
2. **マイアプリ → アプリを作成** → ユースケースは「その他」→ 種類は「**ビジネス**」
   - アプリ名: `SNS Insight Matcher`（表示用。後から変更可）
3. アプリのダッシュボード → **製品を追加** → 「**Facebook ログイン**」を追加
4. **Facebook ログイン → 設定** で以下を登録:
   - **有効な OAuth リダイレクト URI**:
     ```
     https://iefwbgrfgprjpqrnqjka.supabase.co/functions/v1/meta-oauth
     ```
5. **アプリ設定 → ベーシック** で:
   - プライバシーポリシー URL を入力
   - **データ削除リクエスト URL** を入力（[legal.md](legal.md)。必須要件）
   - **アプリ ID** と **app secret** を控える

## 4. シークレットの登録（コマンド1行）

ターミナルでリポジトリ直下に移動して:

```bash
supabase secrets set META_APP_ID=<アプリID> META_APP_SECRET=<app secret>
```

※ `TOKEN_ENCRYPTION_KEY` は設定済み。META の2つを設定した時点で
アプリの「連携する」ボタンが動き始める。

## 5. 開発モードでの動作確認（段階 C）

審査前は**開発モード**のため、連携できるのはアプリに登録した人だけ。

1. アプリダッシュボード → **アプリの役割 → テスター** に自分（と検証协力者）の
   Facebook アカウントを追加
2. Android 実機でアプリを起動 → 設定 → SNS 連携 → **連携する**
3. ブラウザで Meta の認可画面 → 許可 → 「連携が完了しました」→ アプリに戻る
4. アプリの連携状態が「連携中」になり、数分後の初回同期完了で
   「最終同期」日時が表示されれば成功
5. 確認事項（`OI-37`）: `supabase/functions/sync-worker` が取得する指標
   （リーチ・保存数など）が実アカウントで取れているか
   → Supabase ダッシュボード → Table Editor で **private.media_snapshots** を確認

## 6. アプリ審査（段階 D）

申請する権限（コードが使用するもの。過剰申請は審査落ちの原因）:

| 権限 | 用途の説明（審査に書く内容） |
| --- | --- |
| `instagram_basic` | 連携アカウントの基本情報と投稿一覧の取得 |
| `instagram_manage_insights` | 投稿インサイト（リーチ・保存数等）の取得。**数値は非公開の条件判定にのみ使用** |
| `pages_show_list` | Instagram と連携した Facebook ページの特定 |
| `pages_read_engagement` | ページ経由での Instagram アカウント情報の読み取り |

準備するもの:
- [ ] **操作動画**: テストアカウントで「アプリ起動 → SNS 連携 → 認可 → 連携完了 →
      （案件一覧で条件判定が使われる様子）」を画面録画（[assets.md](assets.md)）
- [ ] 各権限の用途説明（上の表を英語でも用意すると通りやすい）
- [ ] 審査用テストユーザーの認証情報

**アプリ審査 → 権限と機能** から上記4つをリクエストして申請する。

## 7. 承認後（段階 E）

1. アプリを **ライブモード** に切り替える
2. 一般の投稿者が連携できることを確認する
3. トークンは約 60 日で失効する。自動更新バッチは Phase 4（T-016）で有効化する

## トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| 「ビジネス／クリエイターアカウントが見つかりません」 | Instagram が個人アカウントのまま、または Facebook ページと未連携。§1 を確認 |
| 「連携を開始できませんでした」 | `META_APP_ID` / `META_APP_SECRET` 未設定（§4） |
| 認可後にエラーページ | リダイレクト URI の登録漏れ・打ち間違い(§3-4) |
| 連携済みなのに同期されない | 開発モードでテスター未登録のアカウント、または権限不足 |
